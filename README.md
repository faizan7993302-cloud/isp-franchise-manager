# FastLink ISP Franchise Management System (Quetta)

A modern, fast, and lightweight Web Application custom-built for managing your Internet Service Provider franchise operations, billing, expenses, and investor accounting.

## 🚀 How to Run the App

### Option 1: Instant Browser Launch (Zero Install)
* Simply double-click **`start.bat`** (or right-click **`index.html`** and open in Google Chrome / Edge).
* Runs completely offline with no dependencies or internet required!

### Option 2: Run with Local Network Server (Access from Mobile Phones)
* Double-click **`run-network-server.bat`**.
* The server will display a local IP (e.g. `http://192.168.1.15:8080`).
* Open that link in any smartphone or tablet connected to the same shop Wi-Fi!

## 🌟 Key Features Included

1. **Dashboard & KPIs:**
   * Active Clients, Monthly Revenue, Panel Cost, Gross Margin (Bachat), and Net Profit.
   * Total Capital & Unspent Liquid Cash tracker.
   * Month-by-month financial progression table (August, September, October).
   * One-click alert for overdue / pending bills.

2. **Client Management & Billing:**
   * Pre-loaded with all **18 registered clients** (Toghi Road, Alamdar Road, Zarghoon Plaza, etc.).
   * Instant toggle between **Paid** and **Pending** status.
   * **💬 1-Click WhatsApp Billing:** Automatically opens WhatsApp with a pre-written Urdu/English payment reminder bill sent directly to the client's number!
   * **🧾 Printable Invoices:** Formatted receipt ready to print on standard A4 or thermal receipt printers.
   * Add, edit, search, and filter clients by Transworld / Ebone.

3. **Expenses (Kharcha) Tracker:**
   * Intelligent separation between **OpEx (Monthly running)** and **CapEx (Equipment assets)**.
   * Splicing machine (PKR 198,000) and shop advance (PKR 25,000) are treated as assets rather than operational loss.
   * Detailed breakdown for Rent, QESCO electricity, Yasir & Rehan salaries, and daily shop expenses.

4. **Hardware & Fiber Inventory (Samaan):**
   * Real-time tracker for Splicing Machine, OLT, ONTs, 12V Adapters, Splitters, and Drop wire.

5. **Upstream Packages Matrix:**
   * Complete pricing and cost table for **38 Transworld & Ebone packages**.
   * Live margin and profit per client comparison.

6. **Investors Hisab & Dividend Calculator:**
   * Transparent record of all 5 investors (Faizan, Faisal, Ameen, Aslam, Hasham) totaling **PKR 13,000,000**.
   * Interactive dividend calculator: enter any net profit amount (e.g. PKR 100,000) and see the exact share distributed to each investor automatically!

7. **Data Backup & Security:**
   * All changes are saved automatically in your browser's persistent storage.
   * Export complete database to **JSON backup** with one click.
   * Export client list to **CSV/Excel**.
